## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Build habit management and tracking on the existing `/calendar` page with a top-level switch between the normal Google Calendar view and a dedicated Habit view. The Habit view follows a full month grid similar to the provided reference: each scheduled habit appears as a compact colored checkbox item inside every applicable day cell, with per-day completion progress. Habit creation/editing/deletion remains available from this page.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
## Incremental implementation plan
1. Add a persisted top-level Calendar/Habits mode switch to the existing `/calendar` page, preserving the normal calendar's month/week controls and Google actions only in Calendar mode.
2. Build the initial dedicated Habit month-grid shell using the same date state/navigation and Atlas styling, with a clear empty state and Add habit affordance; pause for user visual review.
3. Add habit API types/client/hooks and management form/list.
4. Render only scheduled habits in each date cell and wire optimistic completion toggles with rollback.
5. Add progress/loading/error states, focused tests, and final verification.

### Habit table view
- Add a persisted Month/Table sub-view toggle inside Habit mode.
- The table view will show one row per date for the selected month, a progress summary, one checkbox column per active habit, and a completed count, reusing the same schedule filtering and completion state as the month grid.
- Build the table shell during the next visual increment before API wiring so both layouts can be reviewed together.
