## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Build the habit management UI and integrate daily habit checkboxes into the calendar built in LOS-014.04.

**Habit management panel:**
- A collapsible sidebar or drawer on the calendar page listing all active habits.
- Each habit shows: name, color, icon, edit button, delete button (soft-delete with confirm).
- An "Add habit" button opens a small form (InlineCanvasEditor or a Dialog) for name + optional description + color + icon.
- Edit form: same fields, PATCH on save.
- On delete: confirm + DELETE (soft-delete via the backend's archived_at).

**Daily checkboxes on the calendar:**
- Each day cell (in MonthView) and each day column (in WeekView) renders a row of checkboxes — one per active habit.
- Checkbox state fetched from `GET /api/habits/completions?start=&end=` for the visible date range via a `useHabitCompletions` hook (mirror `useSmartBoardPanel`).
- Toggling a checkbox fires `POST /api/habits/completions` and optimistically updates the UI, rolling back on error.
- Re-fetch completions when the visible date range changes (month/week nav).

**Suggested files (under `web/src/features/calendar/components/`):**
- `HabitPanel.tsx` — management list + add/edit/delete forms
- `HabitCheckboxes.tsx` — the row of checkboxes for a single day
- `HabitForm.tsx` — create/edit form (reused in the management panel)

**API client:**
- Extend the `web/src/lib/api/calendar.ts` file (or split out to `web/src/lib/api/habits.ts` if cleaner) with: `listHabits`, `createHabit`, `updateHabit`, `deleteHabit`, `listCompletions(start, end)`, `toggleCompletion(habitId, date)`.
- A `web/src/hooks/useHabits.ts` and `web/src/hooks/useHabitCompletions.ts` mirroring `useSmartBoardPanel`.

**Styling:** Follow Atlas. Each habit gets a small color dot next to its checkbox (from the habit's `color` field). Keep checkboxes compact so they fit inside a calendar day cell without crowding.

**Depends on:** LOS-014.03 (habits backend) and LOS-014.04 (calendar page where the checkboxes render). The calendar day cells need to expose a slot for the habit checkboxes — so implementer should coordinate with LOS-014.04's implementer (or, per the backlog conventions, just read the code once LOS-014.04 is merged and integrate).
