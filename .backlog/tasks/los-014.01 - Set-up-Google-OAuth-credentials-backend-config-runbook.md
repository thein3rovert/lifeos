## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Guide the user through the Google Cloud Console setup (or do it live via pairing) and wire the OAuth credentials into the Go backend config.

Steps:
1. Create a Google Cloud project (or use the existing one)
2. Enable the Google Calendar API
3. Configure the OAuth consent screen (type: Desktop app or Web app depending on redirect flow)
4. Create OAuth client ID + secret
5. Register the redirect URI that the backend will use (e.g., `http://localhost:6060/api/calendar/oauth/callback`)
6. Enable the Calendar API scopes: `calendar.events` (read/write), `calendar.readonly` doesn't apply since this is bidirectional
7. Store credentials in `.env` and add empty placeholders to `.env.example`
8. Add required Go dependencies: `google.golang.org/api/calendar/v3`, `golang.org/x/oauth2`, `google.golang.org/api/option`
9. Write a setup runbook at `doc/google-calendar-oauth-setup.md` (mirrors `doc/smartboard-scheduler-settings-plan.md` style) so future agents/users can reproduce the setup

**Reference:** https://developers.google.com/calendar/api/quickstart/go is a good starting point for the Go client lib.
