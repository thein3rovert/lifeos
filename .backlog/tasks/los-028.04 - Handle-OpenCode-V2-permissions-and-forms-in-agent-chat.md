## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Surface pending OpenCode permission requests and interactive forms inside the LifeOS floating chat so users can approve reject or answer them without opening the OpenCode terminal client.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Pending permission requests appear in the active LifeOS conversation
- [x] #2 Users can approve once approve always or reject a permission request
- [x] #3 Pending forms render supported fields and submit validated answers
- [x] #4 Cancelled settled and failed requests show clear states
- [x] #5 Permission and form interactions are covered by integration and frontend tests
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Extend the sidecar with OpenCode V2 permission and form list/reply/cancel endpoints scoped to the exact active session. 2. Add secure Go conversation-level proxies that resolve private session IDs. 3. Surface pending permission requests and forms in FloatingChat with approve-once, approve-always, reject, answer, and cancel actions plus clear settled/error states. 4. Refresh from live events and direct API reads, and add sidecar, Go, and frontend tests.
